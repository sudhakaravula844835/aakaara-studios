Card exit — what should happen?

The bug: after card 1 leaves the featured (center) position, it's fully visible as it slides upward-left — same corridor as the incoming cards. No sense of orbit, just a slide.

Watch the animated demos below. All four show the same number of cards and the same orbit timing — only the exit behavior changes.

Current · Bug

Visible Slide

Exit travels the same upper-left corridor as incoming cards. Fully opaque — clearly visible sliding upward.

Recommended · A

Graceful Fade

Same geometry. Opacity collapses immediately after featured — the upward slide becomes invisible. Minimal code change.

Option · B

Depth Disappear

After featured, card shrinks toward a vanishing point (tz push) and fades. Cinematic "receding into the scene" feel.

Option · C

Continuous Flow

Redesign exit slots to continue the diagonal downward-right. Cards travel one direction only — true conveyor loop. Requires slot geometry rethink.
